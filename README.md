# datacamp-students-mental-health_project
# Analyzing Students' Mental Health in SQL

## Project Overview
This project explores a dataset from a 2018 survey conducted by a Japanese international university to analyze the mental health profiles of international students. The goal is to see if international students experience higher risks of mental health issues (Depression, Social Connectedness, Acculturative Stress) and whether their length of stay is a contributing factor.

## Tech Stack
* **Database Language:** PostgreSQL (Structured Query Language)
* **Concepts Used:** Aggregation functions (`AVG`, `COUNT`), Grouping (`GROUP BY`), Sorting (`ORDER BY`), Data Filtering, Formatting Numeric Output (`ROUND`)

## Key Queries & Analysis
The final analysis groups student mental health diagnostic scores (PHQ-9, SCS, and ASISS test instruments) against their cumulative length of stay to extract trends and baseline metrics.
